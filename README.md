## 👋 About

I'm Cristian — a senior fullstack engineer. For six years I've built event-driven microservices in .NET and the
React and Angular interfaces on top of them, for travel, insurance and enterprise platforms serving **1M+ customers**.

I own the hard parts: the cache that decides whether search is fast, the queue that decides whether an order survives
a bad deploy, the retry policy that decides whether a supplier outage becomes your outage.

I take on client work through **[Crisify](https://github.com/Crisify)**, my own studio.

## ⚡ Impact

| | Result | How |
|:-:|---|---|
| 🚀 | **Search from 3s to 200ms** | Pre-computed availability hash tables replacing request-time REST fan-out across 160 suppliers |
| 🗄️ | **Search data off SQL Server** | PostgreSQL + ElastiCache for high-volume data, DynamoDB as the inventory cache layer |
| 🛡️ | **160 supplier integrations kept stable** | Redis-backed distributed semaphore, Polly retries, Nginx rate limiting |
| 🔄 | **Stale availability eliminated** | Databricks + .NET pipeline auto-querying suppliers on an event-driven architecture |
| 🤝 | **44k brokers connected to 100 insurers** | REST microservices for contract signing across DACH, choreography-based transfer services |
| ✍️ | **Contract signing migrated without a break** | Backward-compatible move of the whole document-to-signature workflow |
